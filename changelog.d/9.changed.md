`Waiting` now requires a store-generated UUIDv4 `submission_id`, and `Ledger.grant` takes the chosen `Waiting` instead of a ticket id.
wicket does not apply database migrations: for existing PostgreSQL tables, stop producers and workers, apply the [submission ID migration](https://github.com/deyna256/wicket/blob/main/docs/decisions/0007-postgres-store.md#adding-submission-ids-to-an-existing-table) through the application's own migrations, upgrade the library and custom ledger implementations, then resume; new tables already include the column in their metadata.
